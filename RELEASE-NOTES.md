# pcu20d v1.0.0

Первый релиз нативного сервера файлового обмена Siemens PCU20 для FreeBSD.

- Готовый бинарник для FreeBSD 13.5-RELEASE amd64 без Python и сторонних библиотек.
- Каталоги, чтение/запись, создание, удаление и переименование.
- INI-конфигурация, IP ACL и проверка учётных данных.
- rc.d, автозапуск, supervisor и атомарная запись.
- На реальной стойке подтверждены просмотр, создание и копирование файлов.

Бинарник и исходный C-код сохранены без изменений относительно проверенной сборки.
В публичном комплекте используются обезличенные настройки и пользователь ОС pcu20.
Перед установкой настройте INI по README; существующие установки не требуют обновления.
Публичные шаблоны установки отдельно на реальном оборудовании не проверялись.
Другие версии FreeBSD и модели HMI не проверены.
