# pcu20d

Нативный сервер файлового обмена Siemens PCU20 для FreeBSD.
Релиз **v1.0.0**, 6 ноября 2026 года. Независимый проект, не официальный продукт Siemens.

Реализует бинарный TCP-протокол PCU20Net, включая порт 6754.
SMB/Samba и FTP для этого обмена не требуются.

## Возможности

- Просмотр каталогов, чтение и запись файлов, создание каталогов, удаление и переименование.
- INI-конфигурация, ограничение клиентов по IP, проверка имени пользователя и пароля.
- Атомарная запись файлов, ограничение размера, защита от выхода за пределы общей папки.
- Служба FreeBSD rc.d с автозапуском и перезапуском после аварийного завершения.
- C11/POSIX без сторонних библиотек; Python для запуска не нужен.

## Поддержка и проверка

Готовый бинарник предназначен для **FreeBSD 13.5-RELEASE amd64**.
Зависимости: системные libc.so.7, libm.so.5 и ld-elf.so.1.
Другие версии ОС и модели HMI не проверены.

На реальной PCU20 подтверждены просмотр каталога, создание и копирование файлов.
Передача между сервером и флеш-картой стойки быстрая в обоих направлениях.
При записи во внутренний workspace наблюдалось замедление; точная внутренняя причина не установлена.
Отдельный отказ соединения оказался связан со сменой адреса сервера в настройках стойки.
Это не означает проверки всех команд на реальном оборудовании.

До полевых испытаний исходный комплект прошёл 32 протокольных теста,
5 проверок режимов и 8 проверок установки/службы в гостевой FreeBSD 13.5.
Публичные шаблоны конфигурации и установщика обобщены отдельно и на стойке не испытывались.

## Установка готового релиза

Скачайте архив `pcu20d-v1.0.0-freebsd13.5-amd64.tar.gz` из Releases.
В комплекте уже есть бинарник. Установка на сервер без интернета поддерживается.

```sh
tar -xzf pcu20d-v1.0.0-freebsd13.5-amd64.tar.gz
cd pcu20d-v1.0.0-freebsd13.5-amd64
sha256 -c SHA256SUMS
```

Сначала установите комплект, затем отредактируйте установленный файл
`/usr/local/etc/pcu20d.ini`:
`listen` — IP сервера, `allowed_clients` — IP стойки с `/32`,
`username` и `password` — данные подключения стойки.
Начальный шаблон слушает только localhost.
Имя общей папки — `PCU20`, каталог — `/srv/pcu20`.

Установщик проверяет SHA256 всех комплектных файлов.

```sh
pw useradd -n pcu20 -d /nonexistent -s /usr/sbin/nologin -w no
sh install.sh
vi /usr/local/etc/pcu20d.ini
service pcu20d restart
```

Команду `pw useradd` выполняют только при отсутствии пользователя `pcu20`.
Служебной учётной записи ОС пароль входа не нужен: данные протокола проверяются по INI.
На стойке задайте `\\АДРЕС_СЕРВЕРА\PCU20` и те же данные подключения.
Разрешите выбранные TCP-порты для IP стойки.

Существующий INI установщик сохраняет; новый образец кладёт рядом с расширением `.new`.
При обновлении установки с другим пользователем ОС сначала согласуйте владельцев папки,
настройку `pcu20d_account` и права конфигурации; публичный установщик использует `pcu20`.

```sh
service pcu20d status
service pcu20d restart
service pcu20d stop
/usr/local/sbin/pcu20d --version
/usr/local/sbin/pcu20d -c /usr/local/etc/pcu20d.ini --check-config
```

Файл `.pcu20-lock` служебный и остаётся после завершения операций.
Само его наличие не означает занятую блокировку.

## Сборка из исходников

На FreeBSD с базовым компилятором:

```sh
make
```

Это создаёт `pcu20d` в корне проекта. Исходный архив GitHub не включает готовый бинарник
и установочный SHA256SUMS; для готовой установки используйте приложенный архив Releases.
Описание восстановленного протокола: [PROTOCOL.md](PROTOCOL.md).
